## 0. The one-paragraph brief

Ask Mike is a health-plan intake that consumers fill in at their kitchen table,
usually a little worried, before meeting their insurance agent. The identity is
deliberately quiet: paper-warm backgrounds, a soft blue drawn from the Prudential
family, one amber accent that carries all the encouragement, and a serif for
headings so the form reads as written by a person rather than generated by a
system. **Nothing on screen should raise the reader's heart rate.** No urgency,
no gradients, no glow, no shadows deeper than a whisper.

## 1. Colour tokens

Prudential Logo Blue (`#007BC3`) and Pru Navy (`#002247`) are the starting point.
Ours are two steps warmer and one step lighter, so we sit in the family without
impersonating them.

```css
:root {
  /* Ink */
  --am-ink:        #14304A;  /* headings, primary text */
  --am-ink-soft:   #4A6076;  /* body, helper text */
  --am-muted:      #7C8FA3;  /* labels, eyebrows, meta */

  /* Blue — primary */
  --am-blue-800:   #083F66;
  --am-blue-700:   #0B5E96;  /* hover / pressed */
  --am-blue-600:   #0F7CC0;  /* PRIMARY */
  --am-blue-300:   #7FBCE4;
  --am-blue-100:   #E3F0F9;  /* focus ring, progress track */
  --am-blue-50:    #F2F8FC;  /* selected row, tinted panel */

  /* Amber — the single accent */
  --am-amber-600:  #C67E32;  /* amber text on amber-100 */
  --am-amber-500:  #E8973F;
  --am-amber-400:  #F2A65A;  /* MARK, accents */
  --am-amber-100:  #FBEEDD;  /* "why we ask" callouts */
  --am-amber-text: #8A5A1E;  /* text inside amber-100 */

  /* Support */
  --am-green:      #2E8B72;  /* saved, complete, positive */
  --am-green-100:  #E4F1EC;
  --am-alert:      #B4472E;  /* errors — never used for urgency */
  --am-alert-100:  #F8E9E5;

  /* Surface */
  --am-paper:      #FCFBF8;  /* page background — warm, never pure white */
  --am-white:      #FFFFFF;  /* cards */
  --am-line:       #E0E8EF;  /* borders */
  --am-line-soft:  #F0F4F8;  /* internal dividers */
}
```

Rules:
- Page background is **`--am-paper`**, cards are white. Never white-on-white.
- Amber is **never** a button fill and never means "warning". It means
  "here is something helpful". Errors are `--am-alert`, and only ever on
  a field the user actually got wrong.
- Maximum two accent colours on any one screen.

## 2. Typography

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Instrument+Sans:ital,wght@0,400;0,500;0,600;1,400&family=Instrument+Serif:ital@0;1&display=swap" rel="stylesheet">
```

**Instrument Serif** — page titles and step headings only. Nothing else, ever.
**Instrument Sans** — questions, options, helper text, buttons, numbers.

| Role | Size / line-height / weight | Colour | Notes |
|---|---|---|---|
| Page title | 42–48 / 1.06 / 400 serif, −0.02em | ink | One per screen |
| Step heading | 34 / 1.1 / 400 serif | ink | |
| Section eyebrow | 12 / 1 / 600, .12em, uppercase | muted | Above the heading |
| Question | 21 / 1.35 / 500 sans | ink | The `<label>` |
| Body | 17 / 1.65 / 400 sans | ink-soft | Larger than typical — people read this carefully |
| Option label | 16 / 1.5 / 400 sans | ink | |
| Helper | 14 / 1.55 / 400 sans | ink-soft | Under the question, above the control |
| Meta / step count | 14 / 1.4 / 400 sans | muted | |

Body and question text sit in a **620px measure**. Never full-bleed paragraphs.
All numeric inputs and displayed figures use `font-variant-numeric: tabular-nums`.
`text-wrap: pretty` on every paragraph and heading.

## 3. Logo

The mark is **The Reply** — a wide, soft-cornered speech bubble with a warm
light inside. It says the product's name back to you before you have read a
word. Round corners and a single flat fill keep it friendly rather than
official; the amber dot means someone is already in there, waiting. Explicitly
*not* a rock, shield, padlock or umbrella.

### Mark (48×48 viewBox, scales to 16px)

```jsx
export function AskMikeMark({ size = 32, fill = '#0F7CC0', dot = '#F2A65A' }) {
  return (
    <svg width={size} height={size} viewBox="0 0 48 48" fill="none" aria-hidden="true">
      <path
        d="M6 17a11 11 0 0 1 11-11h14a11 11 0 0 1 11 11v7a11 11 0 0 1-11 11h-8l-9 6.5V35A11 11 0 0 1 6 24z"
        fill={fill}
      />
      <circle cx="24" cy="20.5" r="5.5" fill={dot} />
    </svg>
  );
}
```

**Small sizes (20px and below).** The tail and the corner radii collapse. Use
this fatter variant for the favicon and any inline glyph:

```jsx
<path d="M5 16.5a11.5 11.5 0 0 1 11.5-11.5h15A11.5 11.5 0 0 1 43 16.5v8A11.5 11.5 0 0 1 31.5 36h-8l-9 7v-7.3A11.5 11.5 0 0 1 5 24.5z" fill={fill} />
<circle cx="24" cy="20.5" r="6" fill={dot} />
```

Never outline the bubble, never add a drop shadow, never animate the dot as a
typing indicator — that turns the logo into a loading state.

### Lockup

```jsx
export function AskMikeLogo({ size = 32, dark = false }) {
  return (
    <span className="inline-flex items-center gap-[0.34em]">
      <AskMikeMark size={size} fill={dark ? '#FCFBF8' : '#0F7CC0'} />
      <span
        className="font-display leading-none tracking-[-0.015em]"
        style={{ fontSize: size * 0.82, color: dark ? '#FCFBF8' : '#14304A' }}
      >
        Ask Mike
      </span>
    </span>
  );
}
```

- Wordmark is Instrument Serif 400, sentence case: **Ask Mike**. Never all-caps,
  never "ASKMIKE", never bold.
- Gap between mark and wordmark = 0.34 × mark height.
- Clear space on all sides = the mark's height.
- Approved colourways: blue mark + ink wordmark on paper/white; white mark +
  white wordmark on ink; all-ink monochrome. The amber dot stays amber in every
  colourway — it is the one thing that never goes monochrome.
- On navy, fill the bubble `#FCFBF8`, not pure white.

### Alternates (kept on file, not in use)

- **The Arch** — an open doorway with the amber dot inside. More distinctive and
  further from the category, but it asks the viewer to work out what it means.
- **The Spark** — a soft-lobed four-point star with a small amber companion.
  Signals intelligence, but promises cleverness at a moment when people want to
  be told it will be alright.

## 4. Components

### Shape and depth

- Radii: controls and buttons **12px**, cards **18px**, panels/hero **24px**.
- Borders do the work, not shadows. Default card: `1px solid var(--am-line)`,
  optional `0 1px 2px rgba(20,48,74,.04)`. Nothing heavier anywhere.
- Focus is always `2px` border in `--am-blue-600` plus a `4px` ring in
  `--am-blue-100`. Never remove the outline without replacing it.
- Every interactive target is at least 44px tall; primary controls are 48px.

### Buttons

| Variant | Fill | Text | Border | Hover |
|---|---|---|---|---|
| Primary | `blue-600` | white | none | `blue-700` |
| Secondary | white | `blue-700` | `1.5px #C6DDEE` | border `blue-600`, bg `blue-50` |
| Quiet | transparent | `ink-soft` | none | text `ink` |
| Destructive | white | `alert` | `1.5px #E8C4BA` | bg `alert-100` |

16px / 600 weight, `12px` radius, `14px 26px` padding. No uppercase, no icons
inside buttons unless the action is genuinely ambiguous. Primary button label is
always a verb the user would say out loud: *Continue*, *Send to my agent*.
A quiet **Save and finish later** sits beside the primary on every step.

### Choice (radio / checkbox rows)

The single most-used component in this product — a 50-question form is mostly
these. Full-width tappable rows, never bare inputs.

```
unselected  1.5px line border · white · 16px/18px padding · 12px radius
hover       border #C6DDEE · bg paper
selected    1.5px blue-600 border · bg blue-50 · 6px-ring dot in blue-600
```

Stack them with `flex flex-col gap-[10px]`. Multi-select uses the same row with
a 6px-radius square instead of a circle.

### Fields

Label (question, 21/500) → helper (14, ink-soft) → control. Never placeholder-as-label.
`1.5px` border, 12px radius, 13px/16px padding, 17px text.
Prefix `$` and suffix units (`people`, `years`) live outside the input in `--am-muted`
so the typed value stays clean.
The **"I am not sure"** escape hatch is a Quiet-styled toggle *below* the field,
not an option inside it — it must always look like a legitimate answer, because
it is one.

### "Why we ask" callout

The signature component. Amber-100 background, 12px radius, 15px/17px padding,
the bubble glyph (small variant) in `amber-600` with an `amber-100` dot, at 19px, text in `amber-text` at 14/1.55.
Collapsed by default on the client view; always expanded on the review view.
Never red, never an ⓘ icon, never a tooltip — it is reassurance, not an alert.

### Progress

A 6px `blue-100` track with a `blue-600` fill, 130px wide in the header, beside
plain text: *Step 2 of 10*. No percentages, no confetti, no celebration states.

### Page shell

`bg-paper`, sticky white header with a `--am-line` bottom border containing the
lockup on the left and progress on the right. Content column `max-w-measure`
centred, `56px` top padding, `64px` bottom. One question group per card.

## 5. Voice

Already correct on the draft site. Keep it.

**Principles**
1. **Plain, not simple.** Short words for hard things. Never simplify the
   substance — "the 400 percent cliff is back for 2026" stays.
2. **Say why.** Any question that could feel intrusive earns a reason under it.
3. **No urgency.** No countdowns, no scarcity, no "don't miss out". Deadlines are
   stated once, as facts.
4. **Credit the agent.** The software prepares; a person decides. Never claim to
   give advice.
5. **Permission to be unsure.** "Rough answers are fine" is the tone of the whole
   product.

**Mechanics:** sentence case everywhere, including buttons and headings. Second
person. No exclamation marks. No emoji. Numbers as numerals. Currency as
`$1,240`. Contractions sparingly — the draft's slightly formal register
("I am not sure", "do not") is deliberate and reads as careful, not stiff.

| Write | Not |
|---|---|
| Before we meet, tell us about your year | Let's get started on your journey! |
| Your agent uses this to work out which plans are worth your time | Our AI-powered engine optimises your coverage |
| This takes about ten minutes | Just a few quick questions |
| Rough answers are fine | Please provide accurate information |
| Enrollment for 2026 closes 15 January | Only 3 days left to enroll! |

## 6. Motion

150ms `ease-out` on colour and border. 200ms on step transitions — a short
cross-fade with an 8px vertical slide, nothing more. `prefers-reduced-motion`
removes all of it. No skeleton shimmer, no spinners longer than a heartbeat, no
loading copy that jokes about how hard the AI is working.
